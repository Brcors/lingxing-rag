# 领星 API 接入鉴权更新说明

来源：https://apidoc.lingxing.com/new/guides/new-instructions/
核验日期：2026-10-28。本说明是官方接入指南的摘要，用于补充本地旧文档中的过渡期调用示例。

## 公共请求参数与 token 迁移

调用领星业务接口时，当前官方接入指南推荐通过 HTTP 请求头传递 access_token：

```http
Authorization: Bearer <access_token>
```

app_key、timestamp、sign 仍通过 URL Query 传递。业务接口通过 URL Query 传递 access_token 的方式只在过渡期兼容，将于 2027-01-01 正式下线。

## 签名与业务参数

即使 token 放入请求头，计算签名时，仍须将原始 token 以 access_token 为参数名加入签名参数集合，且只参与一次。Authorization 字段名、Bearer 前缀和 sign 本身不加入签名参数集合。

GET 的业务参数位于 URL Query。POST 的业务参数位于 JSON 请求体，业务参数仍按签名规则参与签名计算。接口无特殊要求时使用 Content-Type: application/json。

本迁移说明适用于业务接口；获取和续约 access_token 的接口传参方式不因本说明改变。具体业务字段、请求方法和路径以对应接口文档为准。
